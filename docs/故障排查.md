# 故障排查

按「哪一步出问题」来查。

---

## A. 电脑端启动就报错

### `ModuleNotFoundError: No module named 'winrt'`

依赖没装全。执行：

```powershell
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple winrt-runtime winrt-Windows.Foundation winrt-Windows.Foundation.Collections winrt-Windows.Storage.Streams winrt-Windows.Devices.Bluetooth winrt-Windows.Devices.Bluetooth.GenericAttributeProfile winrt-Windows.Devices.Bluetooth.Advertisement
```

装完先跑 `python pc_server.py --self-test` 确认。

### `创建 GATT 服务失败：RadioNotAvailable`

蓝牙被关了，或者被飞行模式禁用。打开 Windows 设置 → 蓝牙和其他设备 → 蓝牙开关。

### `创建 GATT 服务失败：...` 其他错误码

看 `pc_server.log`。常见原因：

- 蓝牙驱动太老，不支持 BLE 外设模式 → 更新蓝牙驱动
- 电脑只有经典蓝牙没有 BLE → 硬件不支持，换 USB 蓝牙适配器（要支持 BLE 4.0+）

### 能启动，但提示「无法设置蓝牙广播名」

不致命。这种情况下手机扫描时看到的是电脑的系统蓝牙名（比如 `DESKTOP-XXXX`），
App 会把附近的设备都列出来，**在「附近的其他设备」里手动点一下那个名字**也能连。

---

## B. 手机扫不到电脑

按顺序排查：

1. **服务在跑吗**——电脑端窗口还开着吗？关掉窗口就等于停服
2. **手机蓝牙开了吗**——下拉通知栏确认
3. **距离**——拉近到 2~3 米内再扫
4. **权限**——手机设置 → 应用 → 电脑关机 → 权限 → 「附近的设备」要允许
   （小米机型可能在「设置 → 应用设置 → 应用管理 → 电脑关机 → 权限管理」）
5. **电脑蓝牙是不是被别的程序占用了**——关掉其他蓝牙调试工具
6. **重启蓝牙**——电脑和手机各关一次蓝牙再打开
7. 走到这一步还不行，在电脑上跑 `python pc_server.py --list-api`，
   把输出连同 `pc_server.log` 一起看

> 补充：App 里不只有 `PC-Shutdown` 一个条目。「附近的其他设备」列表列出的是所有扫描到的
> BLE 设备，点任意一个都能连（手机端不挑名字），所以即使广播名没设上也能用。

---

## C. 连上了但一直「握手中」/ 超时

App 里会显示 `连接超时（15 秒）`。

- 电脑端服务真的在运行吗（窗口还在吗）
- 距离是否太远
- 手机上把这个连接断掉重连一次
- 电脑端 `pc_server.log` 里有没有出现「客户端已订阅通知」——没有的话说明连接没真正建立，
  大概率是蓝牙栈问题，重启电脑蓝牙试

---

## D. 一直「需要认证」或 PIN 不对

1. **核对 PIN**——电脑窗口里那行 `PIN : xxxxxx`，每次启动都会变
2. **PIN 记错了怎么办**——App 里点「手动输入 PIN」重新填
3. 电脑端 `pc_server.log` 会记 `认证失败（第 N 次）`，连错 5 次会锁定 30 秒，等一会儿重连即可
4. 手机换过、或者清过 App 数据，会重新要 PIN，正常

---

## E. 认证过了，但按钮点不动 / 报错

| 提示 | 原因 |
| --- | --- |
| `ERR NEED_AUTH` | 认证掉的，重连一次 |
| `ERR UNKNOWN_CMD` | 两端版本不一致，重新编译安装最新 APK |
| `发送失败` | GATT 忙，等一秒再点；仍失败就断开重连 |
| `关机失败 - 被系统拒绝` | 关机权限不足，用管理员身份重开一次服务 |

---

## F. 关机命令没生效

- 默认有 **10 秒倒计时**，等一会儿；想立刻关就在 `config.json` 里把
  `shutdown_delay_seconds` 改成 `0`
- 如果之前手动执行过 `shutdown`，Windows 会报「已有待执行的关机计划」（退出码 1190），
  先发一次「取消关机」
- `--dry-run` 模式下**永远不会真的关机**，确认是不是在用演练模式

---

## G. 编译 APK 失败（只有改代码才需要）

```powershell
powershell -ExecutionPolicy Bypass -File .\build-apk.ps1
```

| 报错 | 处理 |
| --- | --- |
| `Could not initialize native services` | 必须设置 `GRADLE_USER_HOME`，脚本已处理；手动跑要自己设 |
| `SDK location not found` | 检查 `android\local.properties` 里的 `sdk.dir` |
| 依赖下载超时 | 脚本已配阿里云镜像；仍失败就换网络重试 |
| `Unsupported class file major version` | 必须用 JDK 17+（本项目用 21） |

---

## H. 想彻底重置

1. 关掉电脑端服务窗口
2. 删掉 `pc-server\pc_server.log`（可选）
3. 手机上：设置 → 应用 → 电脑关机 → 存储 → 清除数据（会忘掉 PIN）
4. 重新启动服务，重新连一次
