# 使用说明

## 一、准备

| | 需要满足 |
| --- | --- |
| 电脑 | Windows 10 1809 及以上；蓝牙已开启；装了 Python 3.9+ |
| 手机 | Android 8.0 及以上；蓝牙已开启 |

---

## 二、电脑端

### 1. 装依赖（只做一次）

打开 PowerShell：

```powershell
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple winrt-runtime winrt-Windows.Foundation winrt-Windows.Foundation.Collections winrt-Windows.Storage.Streams winrt-Windows.Devices.Bluetooth winrt-Windows.Devices.Bluetooth.GenericAttributeProfile winrt-Windows.Devices.Bluetooth.Advertisement
```

### 2. 自检（建议先跑，只读不关机）

```powershell
cd pc-server
python pc_server.py --self-test
```

看到一片 `✓` 和 `自检结果 : 通过 ✓` 就可以继续。

### 3. 启动服务

```powershell
python pc_server.py
```

或者双击 `pc-server\启动服务.bat`。

窗口里会出现：

```
  Bluetooth name : PC-Shutdown
  PIN            : 481920
  Shutdown delay : 10 seconds
```

**把这个 PIN 记下来**，手机第一次连接要用。窗口不要关——关掉就等于停服。

想先试跑不关机：`python pc_server.py --dry-run`

---

## 三、手机端

### 1. 安装

把 `dist\电脑关机.apk` 拷到手机点安装；或者用 USB 连电脑后执行：

```powershell
adb install -r "dist\电脑关机.apk"
```

小米/红米手机第一次装需要允许「安装未知来源应用」。若被 MIUI 拦截，
安装时选择「继续安装」或临时关闭「安全扫描」。

### 2. 首次使用

1. 打开 App，同意「附近的设备」权限（**必须允许**，否则扫不到蓝牙）
2. 确认电脑端服务已经在运行
3. 点「扫描电脑」
4. 列表出现 **★ PC-Shutdown** 后，点「连接电脑」
5. 弹出 PIN 输入框 → 填电脑窗口里那 6 位数 → 确定
6. 顶部状态变成绿色「已认证」，下面 6 个按钮变亮

### 3. 日常使用

只要电脑端服务在跑，打开 App 点「连接电脑」就能直接连（PIN 已记住）。
断线了重新点一次即可。

## 四、都用了什么

| 按钮 | 电脑上实际发生的事 |
| --- | --- |
| 关机 | `shutdown /s /t 10` —— 10 秒后关机，期间可取消 |
| 重启 | `shutdown /r /t 10` |
| 睡眠 | `rundll32 powrprof.dll,SetSuspendState` —— 进入睡眠 |
| 取消关机 | `shutdown /a` —— 撤销倒计时 |
| 查询状态 | 读取电脑端是否有待执行的关机计划 |
| 测试连通 | 发 `PING`，电脑回 `PONG` |

想改倒计时或固定 PIN，见 `pc-server\README.md` 里的 `config.json` 说明。

---

## 五、关于开机

**做不到，这是物理限制。** 电脑关机后蓝牙适配器也断电了，手机上根本扫不到它，
自然发不了任何命令。常见的替代方案：

- 电脑 BIOS 里开启「RTC 定时开机 / Wake on AC」，让电脑定时自己开
- 用支持来电唤醒的插排，配合手机远程给电脑通电

本项目只负责「关机」这一个方向。
