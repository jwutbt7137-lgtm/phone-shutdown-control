# 手机蓝牙遥控电脑关机

用手机通过**蓝牙低功耗（BLE）**连到电脑，远程把电脑关机 / 重启 / 睡眠。
只有关机方向——**开机不在范围内**：电脑关机后蓝牙也跟着断电，物理上无法用蓝牙唤醒，
这是原理限制而不是实现缺陷。

```
┌─────────────────┐        BLE (GATT)         ┌──────────────────┐
│  Android 手机    │  ──────────────────────▶  │   Windows 电脑    │
│  「电脑关机」App │   AUTH <pin>              │  pc_server.py    │
│                 │   SHUTDOWN / RESTART ...  │  → shutdown /s   │
└─────────────────┘                           └──────────────────┘
```

---

## 目录里有什么

| 路径 | 说明 |
| --- | --- |
| `pc-server\` | **电脑端**：Python 服务，开 BLE 服务并执行关机 |
| `android\` | **手机端**：Android 工程源码 |
| `dist\` | 编译好的 APK（已构建则存在） |
| `build-apk.ps1` | 重新编译 APK 的脚本 |
| `docs\` | 安装与使用说明、故障排查、验证记录 |

## 三步用起来

### 第 1 步：电脑端跑起来

```powershell
cd pc-server
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
python pc_server.py
```

窗口里会显示：

```
  蓝牙地址 : F0D41577E411
  广播标识 : 5053443101  （手机 App 靠它认出本机）
  本次 PIN : 481920
```

记下 PIN。也可以直接双击 `pc-server\一键启动（含依赖检查）.bat`，
它会自动装依赖、自检、再启动。

### 第 2 步：手机装 App

把 `dist\电脑关机-debug.apk` 传到手机安装。
或者开 USB 调试后：

```powershell
adb install -r "dist\电脑关机-debug.apk"
```

第一次打开会要「附近的设备」权限，必须允许。

### 第 3 步：连上就能关机

1. App 里点「扫描电脑」→ 出现 **★ 电脑** 条目（靠广播标识识别）→ 点「连接电脑」
2. 弹出 PIN 输入框 → 填电脑窗口里那 6 位数
3. 状态变成「已认证」后，「关机」「重启」等按钮就亮了

> 如果没出现带 ★ 的条目，看「附近的其他设备」里手动点那台电脑也能连——
> 蓝牙名就是电脑在 Windows 设置里显示的名字。

## 功能

| 按钮 | 作用 |
| --- | --- |
| 关机 | `shutdown /s /t 10`，10 秒倒计时（可在设置里改） |
| 重启 | `shutdown /r /t 10` |
| 睡眠 | 让电脑进入睡眠 |
| 取消关机 | `shutdown /a`，撤销还没执行的关机 |
| 查询状态 | 读取电脑端的待执行状态 |
| 测试连通 | 链路 ping，用来确认蓝牙通道正常 |

---

## 安全设计

- **PIN 认证**：电脑端每次启动随机生成 6 位 PIN，手机必须通过认证才能发控制命令。
- **单控制者**：同一时刻只有一台手机是已认证状态。
- **防爆破**：连续输错 5 次即断开该连接。
- **可撤销**：默认 10 秒关机倒计时，误触还能救。
- **审计**：电脑端 `pc_server.log` 记录所有命令。

| | 要求 |
